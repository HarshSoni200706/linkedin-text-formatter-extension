# Extension Screenshots & Visual Assets

All standard promotional and documentation screenshots for the LinkedIn Text Formatter extension are stored in this directory and embedded within `README.md`.

---

## Screenshot Inventory & Assets

The following visual assets are recorded and present in this directory:

1. **`toolbar-selection.png`** — Floating formatting toolbar positioned above a text selection in LinkedIn's post composer.
2. **`bold-result.png`** — Converted Mathematical Bold Unicode text (`𝐁𝐨𝐥𝐝`) inside LinkedIn's post editor.
3. **`layout-a-direct.png`** — Direct-document LinkedIn post composer (Layout A) with active selection.
4. **`layout-b-shadow.png`** — Open Shadow DOM LinkedIn post composer (Layout B) with active selection (`DIV.ql-editor` inside `DIV#interop-outlet`).
5. **`italic-result.png`** — Converted Mathematical Italic Unicode text (`𝐼𝑡𝑎𝑙𝑖𝑐`) inside LinkedIn's post editor.
6. **`underline-result.png`** — Converted Underline Unicode text (`U̲n̲d̲e̲r̲l̲i̲n̲e̲`) with combining low line marks.
7. **`double-underline-result.png`** — Converted Double Underline Unicode text (`D̳o̳u̳b̳l̳e̳ ̳U̳n̳d̳e̳r̳l̳i̳n̲e̲`) with combining double low line marks.

## Screenshot Privacy & Quality Standards

All screenshots adhere strictly to open-source repository guidelines:

- **Privacy Preserved:** No personal accounts, profile pictures, notifications, email addresses, session tokens, or private drafts are exposed.
- **Sample Text:** Uses public, non-sensitive sample text.
- **Format:** Lossless PNG format.
