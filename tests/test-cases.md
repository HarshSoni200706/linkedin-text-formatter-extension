# Formatter Test Cases

Test scenarios and expected outputs for Unicode text transformation:

1. **Lowercase String:** `hello` -> `𝒉𝒆𝒍𝒍𝒐` / `𝗵𝗲𝗹𝗹𝗼`
2. **Uppercase String:** `WORLD` -> `𝑾𝑑𝑑𝑳𝑫` / `𝗪𝗢𝗥𝗟𝗗`
3. **Numbers & Symbols:** `123!`
4. **Emojis:** `Hello 👋 World`
5. **Multiline Input:** `Line 1\nLine 2`
